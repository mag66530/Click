# Версии Click и откат

Файл нужен, чтобы «откати» и «доработай» были однозначными командами, а не
поводом гадать, какую именно версию возвращать.

Текущая версия видна в самом приложении: нажать плашку проекта в шапке –
там строка «Версия».

## Как устроено

| Ветка | Что это |
|---|---|
| `main` | То, что работает у заказчика. Сюда заливается каждая готовая правка. |
| `rollback-good` | Последняя версия, про которую заказчик **сам сказал**, что работает. Метка не двигается, пока это не подтверждено. |
| `before-reviews` | Снимок `main` за минуту до заливки отзывов. Свежий запасной аэродром: новее, чем `rollback-good`, но без новой фичи. |
| `claude/streamlit-migration-review-bgdk6a` | Рабочая ветка. Держится вровень с `main`, тут ведётся доработка. |

Смысл разделения: `main` может уехать вперёд и сломаться, а `rollback-good`
всегда указывает на заведомо живую сборку. Откат – это вернуть `main` на неё.

## Откат

**Быстрый – убрать только отзывы, всё остальное оставить:**

```
git push origin origin/before-reviews:refs/heads/main --force-with-lease
```

**Полный – вернуться к последней подтверждённой заказчиком сборке:**

```
git push origin origin/rollback-good:refs/heads/main --force-with-lease
git push origin origin/rollback-good:refs/heads/claude/streamlit-migration-review-bgdk6a --force-with-lease
```

После отката доработка продолжается в рабочей ветке от этой же точки –
ничего не теряется, сломанные коммиты остаются в истории ветки.

Отдельно про отзывы: фича опциональная. Если она мешает, а откатывать код
не хочется – достаточно **не ставить галочку** «Заодно проверить отзывы»
в «Актуализации». С выключенной галочкой прогон идёт ровно как раньше и в
раздел отзывов не заходит вовсе.

## Когда двигать `rollback-good`

Только после того, как заказчик проверил сборку на живой публикации и
сказал, что всё хорошо:

```
git push origin main:refs/heads/rollback-good --force-with-lease
```

## Важно про скачивание архива

Кнопка «Download ZIP» на GitHub отдаёт **ветку по умолчанию**, а не `main`.
Пока в настройках репозитория по умолчанию стоит рабочая ветка, она держится
вровень с `main` – архив приходит правильный. Если ветку по умолчанию
переключить на `main` (Settings → General → Default branch), связка станет
проще и надёжнее.
