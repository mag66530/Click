# Бот отзывов на своём Windows-компьютере — бесплатно, без карты

Раз бесплатное облако требует карту для верификации (даже без списаний) — самый
честный бесплатный вариант без карты вообще: держать бота на своём компьютере
(или старом запасном ПК/мини-ПК), который включён и подключён к интернету постоянно.

**Условие:** компьютер должен быть включён и онлайн круглосуточно — если его выключать
на ночь или он уходит в сон, бот будет проверять отзывы только пока компьютер работает,
а не "ловить" пропущенное время задним числом.

## 1. Отключить сон/гибернацию компьютера

Иначе Windows сама уснёт и бот перестанет тикать:

- Параметры → Система → Питание и батарея → «Экран и спящий режим»
- И «Питание» / «Сон» → Never / Никогда (для сети и от батареи, если ноутбук)
- Если это ноутбук — лучше держать его подключённым к сети (не от батареи)

## 2. Поставить окружение (один раз)

Откройте PowerShell в папке репозитория (где `requirements.txt`) и выполните:

```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt
playwright install --with-deps chromium
```

Если `Activate.ps1` ругается на политику выполнения скриптов (как было видно в вашем
терминале ранее) — один раз:
```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy RemoteSigned
```

## 3. Настроить `.env`

В корне репозитория создать файл `.env` (если ещё нет) с реальными значениями:

```env
TELEGRAM_BOT_TOKEN=...
MODERATOR_CHAT_ID=123456789,987654321
ADMIN_IDS=123456789
DATABASE_URL=sqlite:///review_bot.db
```

## 4. Накатить миграции (один раз)

```powershell
python migrations\init_db.py
python migrations\add_subscriber_roles.py
python migrations\add_yandex_permalink_id.py
python migrations\add_cookie_path.py
```

## 5. Держать бота живым — простой способ (bat-файл с автоперезапуском)

Готовый файл — `deploy\START-review_bot.bat`. Скопируйте его в корень репозитория
(рядом с `requirements.txt`) и просто дважды кликните — откроется окно консоли,
бот будет работать в нём. Если упадёт — сам перезапустится через 10 секунд.

**Минус:** это окно нужно не закрывать, и при перезагрузке компьютера бот сам не
поднимется — это надо запускать руками. Для полной автономности — шаг 6.

## 6. Автозапуск при включении компьютера (Планировщик заданий Windows)

1. Открыть «Планировщик заданий» (Task Scheduler) — через поиск в Пуске
2. Создать задачу (не «простую задачу», а полную «Создать задачу…»)
3. Вкладка **Общие**: имя «review_bot», отметить «Выполнять вне зависимости от
   регистрации пользователя» — тогда работает и без открытой сессии
4. Вкладка **Триггеры** → Создать → «При запуске компьютера»
5. Вкладка **Действия** → Создать → Программа: путь к `START-review_bot.bat`,
   рабочая папка — папка репозитория
6. Вкладка **Параметры**: отметить «Перезапускать при сбое каждые» — 1 минуту,
   до 999 раз — двойная подстраховка поверх перезапуска внутри самого .bat
7. Сохранить, при необходимости ввести пароль пользователя Windows

Дальше бот будет сам подниматься при каждом включении компьютера, без ручного запуска.

## Проверить, что живой

- В момент, когда бот стартует, он шлёт сообщение всем модераторам
  «🚀 Бот успешно запущен и готов к работе!» (см. `bot/main.py`) — если это сообщение
  не пришло, что-то не так с запуском, смотрите окно консоли/логи
- Логи пишутся в `logs/bot.log` — если бот работает "молча", это первое место, куда смотреть

## Когда появится нормальный сервер

Когда переедете на VDS/сервер (в компании), деплой станет проще и надёжнее —
инструкция для Linux-сервера с systemd уже лежит рядом:
`deploy/README-деплой-бота.md`. Это тот же бот, просто способ держать его живым
меняется с «bat-файл + планировщик» на «systemd-сервис».
