## 1. Как это работает (коротко)

```
Почта (IMAP, раз в 15 мин) ──► парсинг письма ──► проверка, жив ли отзыв
        │
        ├─ Оценка 1–3★  ──► 🚨 алерт в Telegram (БЕЗ генерации ответа)
        │
        └─ Оценка 4–5★  ──► ИИ генерирует ответ ──► сообщение модератору
                                                    [✅ Опубликовать] [✏️ Редактировать]
                                                            │
                                                    Playwright открывает отзыв
                                                    под нужным аккаунтом и публикует
```

- **Чтение почты** — `core/imap_parser.py`, по расписанию из `core/scheduler.py` (каждые 15 минут, часовой пояс Europe/Moscow).
- **Проверка живости отзыва** — `core/review_validator.py` (если отзыв удалён площадкой за время задержки письма — модератора не беспокоим).
- **Генерация ответа** — `core/gpt_client.py` (Gemini).
- **Публикация** — `core/publisher.py` (Playwright, отдельная сессия браузера на каждый бренд).

## 3. Файл `.env` — что и зачем

Лежит в корне проекта. Переменные:

| Переменная | Назначение | Обязательна |
|------------|-----------|-------------|
| `TELEGRAM_BOT_TOKEN` | Токен бота от @BotFather | да |
| `MODERATOR_CHAT_ID` | ID чата/группы, куда приходят уведомления об отзывах | да |
| `ADMIN_IDS` | ID администраторов через запятую (кто управляет ботом) | да |
| `GOOGLE_API_KEY` | Ключ Google AI (Gemini) для генерации ответов | да |
| `DATABASE_URL` | Строка БД. По умолчанию `sqlite:///review_bot.db` | нет |
| `PROXY_URL` | HTTP-прокси для Telegram (если без прокси — удалить строку) | нет |

> После любого изменения `.env` бота нужно **перезапустить** — переменные читаются один раз при старте.

## 4. Сессии для автопубликации (КРИТИЧЕСКИ ВАЖНО)

У каждого бренда — **свой аккаунт** Яндекс Бизнеса / 2ГИС. Чтобы бот мог опубликовать ответ, нужно один раз вручную войти в каждый аккаунт и сохранить сессию браузера.

```powershell
venv\Scripts\Activate.ps1
python migrations/save_cookies.py
```

Скрипт спросит:
1. **Платформу** — `1` (Яндекс Бизнес) или `2` (2ГИС).
2. **Бренд** — номер из списка.

Затем откроется браузер. **Войдите вручную** в аккаунт нужного бренда, дождитесь личного кабинета и нажмите **Enter** в консоли.

Что произойдёт:
- сессия сохранится в `cookies/yandex_<id_бренда>.json` (или `2gis_<id>.json`),
- путь запишется в БД в поле `cookie_file_path` (для Яндекса) или `cookie_2gis_path` (для 2ГИС).

**Повторяйте для каждого бренда отдельно.**

> 🔁 **Сессии устаревают раз в 2–3 недели.** Когда публикация начнёт падать с «нет сессии» / «капча» — просто запустите `save_cookies.py` заново для нужного бренда.
>
> ⚠️ Если сессия не настроена, при нажатии «Опубликовать» бот ответит «🔐 Нет сохранённой сессии для бренда…» и подскажет команду.

## 5. Команды бота (в Telegram)

Все команды доступны **только** пользователям из `ADMIN_IDS`.

| Команда | Что делает |
|---------|-----------|
| `/start` | Приветствие и список команд |
| `/list_brands` | Список брендов: ID, почта, число городов |
| `/add_brand` | Добавить новый бренд (диалог в 3 шага) |
| `/add_city` | Добавить город(а) к бренду |
| `/edit_prompt` | Изменить промт (стиль ответа) бренда |
| `/check_now` | Прямо сейчас проверить почту, не дожидаясь 15 минут |
| `/cancel` | Отменить текущий диалог |

Под каждым сгенерированным ответом — две кнопки:
- **✅ Одобрить и опубликовать** — публикует ответ через браузер.
- **✏️ Редактировать** — пришлите свой текст, бот сохранит и снова предложит опубликовать.

## 6. Как зарегистрировать человека

В системе две роли, они независимы:

### 6.1. Администратор (управляет ботом)
Может слать команды и нажимать кнопки.

1. Человек узнаёт свой Telegram **user_id** — пишет боту **@userinfobot** и получает число (например, `123456789`).
2. В `.env` добавляете этот ID в `ADMIN_IDS` через запятую:
   ```
   ADMIN_IDS=415244843,123456789
   ```
3. **Перезапускаете** бота.

### 6.2. Модератор / чат уведомлений (получает отзывы)
Это **один** чат (`MODERATOR_CHAT_ID`), куда падают все уведомления.

- **Личка:** поставьте `MODERATOR_CHAT_ID` = user_id человека (он должен сначала написать боту `/start`).
- **Группа (рекомендуется для команды):**
  1. Создайте группу, добавьте в неё бота.
  2. Узнайте ID группы (например, через @userinfobot, добавленного в группу, или @getmyid_bot) — у групп ID отрицательный, вида `-100xxxxxxxxxx`.
  3. Пропишите его в `MODERATOR_CHAT_ID` и перезапустите бота.

> Чтобы несколько человек **видели** отзывы — используйте группу. Чтобы несколько человек **управляли** ботом — добавьте их в `ADMIN_IDS`.

## 7. Как добавить / изменить бренд

### 7.1. Добавить новый бренд — `/add_brand`
Бот проведёт по шагам:
1. **Название** (например, `Инметпром`).
2. **Промт** для ИИ. Можно использовать переменные:
   - `{name}` — имя автора отзыва,
   - `{text}` — текст отзыва,
   - `{city}` — город филиала.
3. **IMAP-данные одной строкой**: `логин пароль сервер`
   Пример: `reviews@inmetprom.ru qwerty123 imap.yandex.ru`
   > Пароль — это **пароль приложения** из почты, не основной (см. раздел 9).

После добавления **обязательно**:
- добавьте города — `/add_city`,
- сохраните сессию браузера — `save_cookies.py` (раздел 4).

### 7.2. Изменить стиль ответа (промт) — `/edit_prompt`
Выберите бренд → пришлите новый промт. Бот покажет текущий перед заменой.

### 7.3. Добавить города — `/add_city`
Выберите бренд → введите города через запятую: `Казань, Уфа, Самара`.

### 7.4. Сменить пароль почты бренда ⚠️
В боте **нет** команды смены IMAP-пароля. `/add_brand` на существующее имя выдаст «уже существует».
Варианты:
- **Через БД напрямую** (DB Browser for SQLite или `sqlite3`):
  ```sql
  UPDATE brands SET imap_password='новый_пароль_приложения' WHERE name='Инметпром';
  ```
- Либо отредактировать `migrations/init_db.py` и пересоздать запись.

> 💡 Текст в `/start` обещает, что `/add_brand` умеет «сменить пароль» — это не так, фактически только через БД.

## 8. Глобальные правила ответов ИИ

Файл `core/gpt_client.py`, переменная `GLOBAL_RULES` — применяется ко **всем** брендам:
запрещённые слова, длина ответа, формат упоминания города и т.д.

Чтобы запретить новое слово или поменять стиль для всех брендов сразу — правьте `GLOBAL_RULES`, затем перезапустите бота. Индивидуальный стиль конкретного бренда меняется через `/edit_prompt`.

## 9. Настройка почты Яндекс (IMAP)

1. Почта → Настройки → Все настройки → Почтовые клиенты.
2. Включить **IMAP**.
3. Создать **пароль приложения** (не основной пароль аккаунта!).
4. Параметры: сервер `imap.yandex.ru`, порт `993`, SSL — да.
5. Этот пароль приложения и указывается при `/add_brand` либо в БД.

## 10. Нюансы и подводные камни

- **ИИ — это Gemini, а не ChatGPT.** Нужен валидный `GOOGLE_API_KEY`. Модель — `gemini-1.5-flash` (зашита в `gpt_client.py`).
- **Прокси.** Telegram подключается через `PROXY_URL`. Если прокси отвалится — бот не сможет ни принимать команды, ни слать уведомления. Стартовое сообщение всегда пишет «через прокси», даже если прокси не задан (это просто текст).
- **Негатив не отвечается автоматически.** Отзывы 1–3★ приходят как алерт 🚨 — отвечает человек вручную.
- **Задержка писем.** Почта от площадок приходит с задержкой 1–3 часа. Перед обработкой бот проверяет, жив ли ещё отзыв.
- **Капча Яндекса.** Если при публикации появилась капча — бот пришлёт готовый текст ответа и ссылку, чтобы опубликовать вручную в пару кликов.
- **Селекторы вёрстки.** Яндекс периодически меняет HTML. Если кнопка «Ответить»/«Отправить» не находится — обновите списки `reply_selectors` / `submit_selectors` в `core/publisher.py`. Для отладки сохраняется скриншот `logs/publish_debug.png`.
- **2ГИС: автопубликация не реализована.** Сессию 2ГИС сохранить можно, но `publish_reply_for_review` публикует только через сценарий Яндекса. Для 2ГИС-отзывов ответ публикуйте вручную.
- **Часовой пояс** планировщика — Europe/Moscow.
- **Интервал проверки** жёстко задан 15 минут в `core/scheduler.py` (`minutes=15`).

## 11. Эксплуатация

- **Логи:** `logs/bot.log` (плюс вывод в консоль). Скриншоты отладки публикации — `logs/`.
- **Перезапуск** нужен после изменения `.env`, `GLOBAL_RULES` или кода. Бренды/промты/города меняются на лету через команды — перезапуск не требуется.
- **Продакшен (Linux):** запускать как сервис systemd (пример в README, раздел «Запуск через systemd»). На Windows — через «Планировщик заданий» или просто держать окно консоли / запускать как службу (NSSM).

## 12. Траблшутинг

| Симптом | Причина / решение |
|---------|-------------------|
| Бот не отвечает на команды | Проверь, что твой ID в `ADMIN_IDS`; проверь прокси; смотри `logs/bot.log` |
| «🔐 Нет сохранённой сессии…» | Запусти `python migrations/save_cookies.py` для этого бренда |
| Публикация падает / капча | Сессия устарела или капча — пересохрани cookies или опубликуй вручную |
| Кнопка «Ответить» не найдена | Яндекс сменил вёрстку — обнови селекторы в `core/publisher.py` |
| Ответы ИИ не генерируются | Проверь `GOOGLE_API_KEY` и лимиты Google AI; смотри логи |
| Письма не читаются | Проверь IMAP-пароль приложения и что IMAP включён в почте |
| Отзыв помечен DELETED, но он живой | Подправь логику редиректов в `core/review_validator.py` |
