# ── Мотор: то, из чего собран сам веб-сервер Streamlit ──────────────────────
#
# Эти библиотеки Streamlit тянет за собой сам и разрешает им широкий диапазон
# версий («starlette<2,>=0.40.0»). Облако при каждой пересборке берёт самую
# свежую – и однажды взяло ту, что со Streamlit уже не стыкуется.
#
# Живой случай: starlette 1.4.0. У неё в механизме сжатия ответов появился
# обязательный аргумент thread_minimum_size, а Streamlit 1.60.0 его не
# передаёт. Сервер падал с TypeError на КАЖДОМ запросе и отвечал 500 даже на
# проверку живости – заказчик видел «Oh no. Error running app», и перезапуск
# не помогал: окружение собиралось тем же самым составом.
#
# Отличие от остальных зависимостей в цене поломки. Сломался мотор – белый
# экран, до нашего кода дело не доходит, сделать нельзя ничего. Сломались
# таблицы или картинки – приложение открывается и пишет, что не так.
# Поэтому мотор держим на точных версиях, остальное пусть обновляется.
#
# Взяты версии, которые Streamlit Cloud уже успешно поставил на своём
# Python 3.14 (видно в логе установки) и на которых прогнаны тесты.
